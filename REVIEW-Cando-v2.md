# Review: OurDriedFish

**Reviewer:** Cando, Johanne Froilan T.
**Repository:** https://github.com/Gianne818/OurDriedFish

---

## Project Structure Rating: 10/10

The repository is clean and easy to open, with only a solution file, a .gitignore, and one project folder at the root. The project folder has the same name as the repo, so it is easy to know where to start looking. It has 12 commits that show steady progress, and nothing unnecessary was left in the repo.

---

## Front-End Rating: 10/10

This is a good website, and I really liked the design and how it was done. The look feels clean and well put together, so it was nice to go through. It feels like a project that was made with care.

---

**Overall:** Nice work! A short README would be a nice extra, but the project is in great shape.
